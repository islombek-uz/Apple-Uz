{% if provider_name == 'Google' %}

1. Google Cloud Console’da loyiha tanlang yoki yarating, OAuth consent screen’ni sozlang. Test rejimida kiradigan Google hisobingizni test user sifatida qo‘shing.

2. Credentials → Create credentials → OAuth client ID → Web application’ni tanlang.

3. Authorized redirect URI maydoniga aynan shu manzilni qo‘shing: {{ callback_url }}

4. Yaratilgan Client ID va Client secret’ni loyiha papkasidagi `.env` fayliga kiriting:

{{ client_id_env }}=Google’dan_olingan_Client_ID
{{ secret_env }}=Google’dan_olingan_Client_secret

Client secret’ni chatga yoki frontend kodiga joylamang. `.env` Git’ga qo‘shilmaydi.

5. Django serverini to‘xtatib qayta ishga tushiring, so‘ng Google tugmasini yana bosing.
